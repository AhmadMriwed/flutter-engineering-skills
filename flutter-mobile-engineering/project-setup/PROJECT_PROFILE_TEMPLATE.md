# Project profile template

Copy this structure into PROJECT_PROFILE.md in the destination project after approval. Replace all bracketed fields using the [schema](PROJECT_PROFILE_SCHEMA.md).

| Key | Value |
| --- | --- |
| Project name | [Name] |
| Skills repository version | [Documented release or commit] |
| Architecture profile | [ID and version] |
| State profile | [ID and version] |
| DI profile | [ID and version or none] |
| Networking approach | [Profile or named approach, or none] |
| Storage approach | [Profile or named approach, or none] |
| Navigation approach | [Profile or named approach] |
| Selected dependencies | [Packages and resolved version baseline] |
| Approved exceptions | [Scope, evidence, approval, review trigger, or none] |
| Decision rationale | [Requirements, tradeoffs, and confidence] |
| User approval | [Approved, date, and approval reference] |
