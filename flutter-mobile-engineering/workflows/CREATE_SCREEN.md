# Create screen

Identify the normal entry route, ownership boundary, render states, fields and actions. Choose a screen structure from [UI guidance](../ui/screens/UI_ARCHITECTURE.md), reuse [design system components](../ui/design-system/DESIGN_SYSTEM.md), and use the approved state and navigation integrations. Verify keyboard, constrained layouts, RTL, theme and loss of focus or route lifetime.

For an approved STATE-CUBIT project follow the [Cubit workflow](../state-management/cubit/WORKFLOW.md) and [templates](../state-management/cubit/TEMPLATES.md).
