# Create feature

Read the approved project profile or [discover the existing architecture](../project-setup/PROJECT_DISCOVERY.md). Identify screens, state owner, data contracts, failure behavior and shared components. Follow the chosen architecture workflow. For ARCH-FEATURE + STATE-GETX, use [the reference workflow](../architecture/profiles/feature-first/FEATURE_WORKFLOW.md). Review [UI rules](../ui/screens/UI_ARCHITECTURE.md) and [shared contracts](../core/networking/API_CONTRACTS.md) where relevant. Verify normal navigation, loading, empty, success and failure, including retry and leaving the screen during work.

For an approved STATE-CUBIT project follow the [Cubit workflow](../state-management/cubit/WORKFLOW.md) and [templates](../state-management/cubit/TEMPLATES.md).
