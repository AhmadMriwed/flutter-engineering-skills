# Flutter Engineering Skills

A standalone, evidence-backed knowledge base for building and maintaining Flutter apps. It separates shared engineering standards from selectable architecture, reactive state and dependency-injection profiles.

| Area | Current support |
| --- | --- |
| Architecture | Feature-first layers and typed API boundaries |
| State | GetX reactive controllers and route bindings |
| Dependency injection | GetIt service and repository composition |
| Networking and persistence | Dio behind ApiServices and GetStorage recipes |
| Cubit | Pending reference extraction and compatibility validation |

Start with the [skill](مهارات%20تصميم%20الموبايل/SKILL.md) or [task index](مهارات%20تصميم%20الموبايل/SKILL_INDEX.md). For a new project, present compatible options and record the user's approved selection before scaffolding. For an existing app, discover and preserve its architectural decisions. [Getting started](docs/GETTING_STARTED.md) covers both paths.

Use the same skill tree with [Codex](docs/CODEX_INTEGRATION.md) and [Claude Code](docs/CLAUDE_CODE_INTEGRATION.md).
