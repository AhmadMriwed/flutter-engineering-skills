# Getting started

Open the [central skill](../مهارات%20تصميم%20الموبايل/SKILL.md) and choose your task from the [index](../مهارات%20تصميم%20الموبايل/SKILL_INDEX.md). For a new app, use the project decision workflow before scaffolding. For an existing app, inspect its approved profile and current owner boundaries first. See [project integration](PROJECT_INTEGRATION.md).
