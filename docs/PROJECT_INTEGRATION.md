# Project integration

Use [project decisions](../مهارات%20تصميم%20الموبايل/project-setup/PROJECT_DECISION_WORKFLOW.md) for new projects and [discovery](../مهارات%20تصميم%20الموبايل/project-setup/PROJECT_DISCOVERY.md) for existing ones. Record the central revision and approved profiles in the consuming project's profile. Keep environment endpoints, branding, secrets and product requirements in the consumer. Associate the checkout with a local setting or point the agent to it explicitly. Local symlinks should not be committed when their target is machine-specific.
