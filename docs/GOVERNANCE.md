# Governance

Reference projects supply evidence and remain independent. Propose changes with source revision, observed behavior, scored tradeoffs, compatibility impact, and verification scope. Obtain approval before adopting substantive changes or changing a release version. Keep pending candidates out of the supported options. Use the [source registry](../flutter-mobile-engineering/knowledge-management/SOURCE_REGISTRY.md), [evidence registry](../flutter-mobile-engineering/knowledge-management/EVIDENCE_REGISTRY.md) and [import workflow](../flutter-mobile-engineering/workflows/IMPORT_SKILLS_FROM_PROJECT.md).
