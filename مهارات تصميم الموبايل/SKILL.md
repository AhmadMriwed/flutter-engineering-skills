# Flutter mobile engineering

Use [the task index](SKILL_INDEX.md) to load the relevant standards and profile references.

- New app → follow [project decisions](project-setup/PROJECT_DECISION_WORKFLOW.md). Present eligible choices and tradeoffs, recommend with a confidence limit, and get explicit user approval before writing profile-dependent files. Record approval in PROJECT_PROFILE.md.
- Existing app → read its approved profile and inspect current code with [project discovery](project-setup/PROJECT_DISCOVERY.md). Preserve its architecture and approved exceptions while implementing changes.
- Feature work → use [feature routing](workflows/CREATE_FEATURE.md) and the approved profile's workflow and templates.
- New source → use [reference import](workflows/IMPORT_SKILLS_FROM_PROJECT.md). Preserve provenance and seek approval before substantive changes to adopted practices.

Use the [compatibility matrix](compatibility/COMPATIBILITY_MATRIX.md) to check complete combinations. Pending profiles are evidence collection tracks. Verify behavior and document what was tested.
