# Bootstrap a Flutter project

Complete [project decisions](PROJECT_DECISION_WORKFLOW.md) before executing the selected starter. Once approved, pin the skills revision and profiles, create the project profile, select the SDK and platforms, resolve dependencies, and configure environment, platform identity and tests.

The validated combination uses [the feature-first GetX starter](../architecture/profiles/feature-first/GETX_BOOTSTRAP.md). Keep larger recipes with their owning profile. Read [the profile lock](ARCHITECTURE_LOCK.md) before subsequent feature work.
