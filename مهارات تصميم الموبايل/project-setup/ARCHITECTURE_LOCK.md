# Project profile lock

Read PROJECT_PROFILE.md before changing an existing project. Continue under approved selections for routine feature work, with no repeated stack choice. If the profile is missing, use [discovery](PROJECT_DISCOVERY.md) and follow the existing architecture. Propose migrations with scope, rationale, compatibility, rollout, tests and rollback. Wait for explicit approval before a state management change, material architectural change, or an incompatible integration. Update the project's profile and decision rationale once the approved change is made.
