# Flutter mobile engineering knowledge base

Start with [the task index](SKILL_INDEX.md) or the [agent skill](SKILL.md). Shared guidance lives in core and ui. Architecture, reactive state and dependency injection have separate profiles. The first validated combination is feature-first architecture, GetX and GetIt. Cubit is pending source extraction. New projects require explicit selection before scaffolding.

The original rule IDs and their classifications remain usable. MANDATORY applies within the documented rule scope, DEFAULT is the usual choice, CONDITIONAL applies when its prerequisites hold, OPTIONAL is elective, PROJECT-SPECIFIC remains source-local, INCONSISTENT records variation, NOT IMPLEMENTED records absence, and RECOMMENDED identifies an improvement. See [profile statuses and integration rules](compatibility/INTEGRATION_RULES.md), [source registry](knowledge-management/SOURCE_REGISTRY.md) and [refactor audit](validation/REFACTOR_AUDIT.md).
